Classes

AppInitializer

Boots a request: checks dependencies, loads config and locale, connects the database, optionally authenticates.

AppManager

Builds the Twig environment with theme, translator and extensions, and renders templates for web controllers.

LocaleManager

Sets the gettext locale and text domain for a supported locale from the locale directory.

Bootstrap

Process-level setup the entry points run before routing: timezone and session cookie.

AbstractApiController

Shared base for API controllers: enforces the api.enabled switch, parses JSON input and shapes JSON responses.

DocsController

Serves the Swagger UI page at /api/docs when API documentation is enabled.

JsonController

Serves the OpenAPI JSON specification at /api/docs/json, generated from the V2 controller attributes.

HeadlessNotFoundController

Answers every miss on a headless install, where there is no web interface to render a 404 page with.

HealthController

Unauthenticated readiness probe reporting whether Poweradmin can reach its own dependencies. Disabled by default.

InternalApiController

Base for session-authenticated internal API endpoints: requires a login and the X-CSRF-Token header on writes.

UserPreferencesController

Internal endpoint /api/internal/user-preferences: reads, updates and resets the logged-in user's preferences.

ValidationController

Internal endpoint /api/internal/validation: validates a record against a zone before it is submitted.

ZoneController

Internal endpoint /api/internal/zone: lists or fetches zones the logged-in user may view.

PublicApiController

Base for /api/v2 endpoints: API key or Basic auth, key scope enforcement, request logging and wrapped responses.

V1GoneController

Answers every /api/v1 path with 410 Gone and a pointer to v2.

ChangeRequestsController

/api/v2/change-requests: lists and shows filed change requests, applies a reviewer's decision and lets a requester withdraw their own request.

DynamicDnsController

POST /api/v2/dynamic-dns: updates the A/AAAA records of a hostname in a zone the caller owns.

GroupMembersController

/api/v2/groups/{id}/members: lists, adds and removes the users in a group.

GroupZonesController

/api/v2/groups/{id}/zones: lists, assigns and unassigns the zones a group owns.

GroupsController

/api/v2/groups: lists, creates, updates and deletes user groups.

OpenApiSpec

Carries the OpenAPI spec-level attributes (info, servers, security schemes) for the v2 API. Annotation-only: the class holds no runtime code and exists so the spec root does not live on an arbitrary endpoint controller. The docs generator scans this directory and picks the attributes up from here.

PermissionTemplatesController

/api/v2/permission-templates: lists, creates, updates and deletes permission templates.

PermissionsController

/api/v2/permissions: read-only listing of the permission catalogue and single permissions.

UsersController

/api/v2/users: lists, creates, updates and deletes users and assigns their permission template.

ZoneDnssecController

/api/v2/zones/{id}/dnssec: reports the signing status of a zone and signs or unsigns it.

ZoneMetadataController

/api/v2/zones/{id}/metadata: lists, reads, replaces and deletes PowerDNS metadata kinds on a zone.

ZoneOwnersController

/api/v2/zones/{id}/owners: lists, adds and removes the users who own a zone.

ZoneTemplateRecordsController

/api/v2/zone-templates/{id}/records: lists, creates, updates and deletes the records of a zone template.

ZoneTemplatesController

/api/v2/zone-templates: lists, creates, updates and deletes zone templates.

ZonesChangeRequestsController

/api/v2/zones/{id}/change-requests: files change requests for a zone without writing to it. Answers 404 while approval.enabled is off.

ZonesController

/api/v2/zones: lists, creates, updates and deletes zones.

ZonesRRSetsController

/api/v2/zones/{id}/rrsets: lists, replaces and deletes records grouped by name and type.

ZonesRecordsBulkController

POST /api/v2/zones/{id}/records/bulk: applies a list of create, update and delete record operations.

ZonesRecordsController

/api/v2/zones/{id}/records: lists, creates, updates and deletes single records in a zone.

ChangePasswordController

Handles the change-password form for the logged-in user; LDAP, OIDC and SAML users are refused.

ForgotPasswordController

Handles the forgot-password form: takes an email address and sends the password reset link.

ForgotUsernameController

Handles the forgot-username form: sends the username to the submitted email address if it is on file.

LoginController

Renders the login page with its CSRF token and the enabled OIDC and SAML providers.

LogoutController

Logs the user out, clearing the session and redirecting to the OIDC or SAML provider's logout when used.

MfaSetupController

Handles the MFA setup page: app or email enrolment, verification, disabling and recovery code regeneration.

MfaVerifyController

Handles the MFA verification step after login, with throttling of failed attempts.

OidcCallbackController

Handles the OIDC provider callback at /oidc/callback: completes the login or reports the provider error.

OidcLoginController

Starts the OIDC login flow by redirecting to the chosen or first configured provider.

ResetPasswordController

Handles the password reset form reached from the emailed token link and sets the new password.

SamlCallbackController

Handles the SAML assertion (/saml/acs) and single logout (/saml/sls) endpoints.

SamlLoginController

Starts the SAML login flow by redirecting to the chosen or first configured identity provider.

SamlMetadataController

Serves the SAML service provider metadata XML at /saml/metadata.

UserAgreementController

Handles the user agreement page: shows the text and records the user's acceptance.

BaseController

Base for every web controller: config, database, session, permissions, CSRF, validation and Twig rendering.

DnssecAddKeyController

Handles the add-DNSSEC-key form for a zone: validates key type, bits and algorithm, then creates the key.

DnssecController

Renders the DNSSEC key overview for a zone and handles the unsign-zone action.

DnssecDeleteKeyController

Handles the delete confirmation for a DNSSEC key and removes it from the zone on confirmed POST.

DnssecDsDnskeyController

Renders the DS and DNSKEY records page for a zone.

DnssecEditKeyController

Renders the DNSSEC key detail page that confirms activating or deactivating a key.

DnssecKeyController

Base for the pages that add, edit, toggle, delete, import and export DNSSEC keys: one shared gate.

DnssecKeyExportController

Streams a DNSSEC private key as a PEM file download. Requires PowerDNS 4.7+ which exposes the privatekey field on per-key GETs of /cryptokeys.

DnssecKeyImportController

Imports a PEM-encoded DNSSEC private key into a zone via the PowerDNS API.

DnssecToggleKeyController

Handles the POST that activates or deactivates a DNSSEC key, then returns to the zone's DNSSEC page.

AbstractListLogController

Shared flow for the log listing pages (API, user, group and zone logs): filter parsing, pagination with last-page clamping, and CSV/JSON export.

ListLogApiController

Renders the API request log page for admins with filters and CSV/JSON export.

ListLogGroupsController

Renders the group log page with filters and CSV/JSON export.

ListLogUsersController

Renders the user log page with filters and CSV/JSON export.

ListLogZonesController

Renders the zone log page, limited to owned zones for users without the view-others permission.

AddRecordController

Handles the add-record form for a zone: checks edit rights, validates the record and saves one or several rows.

BatchPtrRecordController

Handles the batch PTR form: creates PTR records for an IPv4 or IPv6 network, optionally with forward records.

BulkRecordAddController

Handles the bulk add-records form for a zone: parses one record per line and saves them as one changeset.

DeleteRecordController

Handles the delete-record confirmation page and removes the record, plus its PTR counterpart when ticked.

DeleteRecordsController

Handles bulk record deletion from search results: shows the selected records and deletes them on confirmation.

EditCommentController

Handles the zone comment form: shows the comment and saves it when the user may edit the zone.

EditRecordController

Handles the edit-record form: validates the change, saves it and syncs the matching PTR record when ticked.

ListRecordChangesController

Renders the record change log page for admins with filters, pagination and CSV/JSON export.

RecordTypeDefaultsController

Admin UI for managing per-record-type default TTLs. The repository drives ReverseTtlResolver::resolveTtlForType(), so values entered here take effect for every record-creation path (UI + API).

AddSupermasterController

Handles the add-supermaster form: validates the IP and nameserver, then stores the supermaster entry.

DatabaseConsistencyController

Renders the database consistency page for admins and applies the fix actions it offers.

DeleteSupermasterController

Handles the delete-supermaster confirmation page and removes the supermaster on confirmed POST.

EditSupermasterController

Handles the edit-supermaster form: updates the IP, nameserver and account of a supermaster.

IndexController

Renders the dashboard after login with the cards allowed by the user's permissions.

ListSupermastersController

Renders the supermasters list at /supermasters.

NotFoundController

Answers unmatched routes with a 404 page, or a JSON error for API callers.

PdnsStatusController

Renders the PowerDNS server status page from the API's server info and statistics.

PingController

Unauthenticated liveness probe. Answers if the process can serve a request and checks nothing else, so it still reports ok while the database is down.

StaticAssetController

Serves static assets like CSS, JS, images and fonts.

AddZoneTemplController

Handles the add-zone-template form: validates name and description, then creates the template.

AddZoneTemplRecordController

Handles the add-record form of a zone template and marks the template as modified on success.

DeleteZoneTemplController

Handles the delete-zone-template confirmation page and deletes the template on confirmed POST.

DeleteZoneTemplRecordController

Handles the delete confirmation for a zone template record and marks the template modified after deletion.

EditZoneTemplController

Renders the zone template edit page and handles detail, record, save-as and linked-zone updates.

EditZoneTemplRecordController

Handles the edit form for one zone template record and saves the change on POST.

ListTemplateZonesController

Renders the list of zones linked to one zone template.

ListZoneTemplController

Renders the zone templates list at /zones/templates.

SaveZoneAsTemplateController

Handles the save-zone-as-template form: creates a zone template from the zone's records.

SetDefaultZoneTemplController

Handles the POST that marks a zone template as the default or clears the default flag.

UnlinkZonesTemplController

Handles unlinking selected zones from a zone template, with a confirmation step.

AddGroupController

Handles the add-group form at /groups/add: validates the name and group template, then creates the group.

AddPermTemplController

Handles the add-permission-template form: validates the fields and creates the template with its permissions.

AddUserController

Handles the add-user form: guards the template choice, creates the user, assigns groups and mails credentials.

ApiKeysController

Renders the API key list page and links to the add, edit, delete and regenerate actions.

DeleteGroupController

Handles the delete-group confirmation page and deletes the group on confirmed POST.

DeletePermTemplController

Handles the delete-permission-template confirmation page and deletes the template on confirmed POST.

DeleteUserController

Handles the delete-user page: deletes the user and transfers or deletes each of their zones as chosen.

EditGroupController

Handles the edit-group form: updates the name, description and permission template of a group.

EditPermTemplController

Handles the edit-permission-template form: updates the template's details and permission set.

EditUserController

Handles the edit-user form: updates the profile, password, template and group memberships of a user.

ListGroupsController

Renders the groups list page at /groups.

ListPermTemplController

Renders the permission templates list at /permissions/templates.

ManageGroupMembersController

Handles the group members page: adds and removes users in a group.

ManageGroupZonesController

Handles the group zones page: assigns zones to a group and removes them.

QuickRemoveGroupMemberController

Handles the POST that removes one user from a group from the edit-group page.

QuickRemoveGroupZoneController

Handles the POST that removes one zone from a group from the edit-group page.

RemoveUserGroupController

Handles the POST that removes a user from one group from the edit-user page.

UserPreferencesController

Handles the user preferences page: rows per page, form positions, display toggles and timezone.

UsersController

Renders the users list and saves the inline edits submitted from it.

AddZoneMasterController

Handles the add-primary-zone form: validates name and kind, applies the template and creates the zone.

AddZoneSlaveController

Handles the add-secondary-zone form: validates the name and primary address, then creates the SLAVE zone.

BulkRegistrationController

Handles the bulk registration form: creates a primary zone from a template for each submitted domain name.

ChangeRequestController

Shows one change request with its before/after actions and takes the reviewer's approve or reject decision, or the requester's cancellation.

DeleteDomainController

Handles the delete-zone confirmation page and deletes the zone on confirmed POST.

DeleteDomainsController

Handles bulk zone deletion from the zone lists: shows the selected zones and deletes them on confirmation.

EditController

Renders the zone edit page with its record table and handles record, comment, template and signing changes.

EditZoneMetadataController

Handles reading and replacing raw PowerDNS domain metadata for a single zone.

ListChangeRequestsController

Lists change requests: reviewers see the zones their approve level covers, everyone else sees the requests they filed.

ListForwardZonesController

Renders the forward zone list with pagination, letter filter and sorting; also handles the API sync action.

ListNetworksController

Lists network -> view mappings (PowerDNS 5.0+) and exposes inline add/edit/remove actions. Admin-only; hidden behind the supportsViews() capability gate, which covers the version, the backend and views=yes.

ListReverseZonesController

Renders the reverse zone list with pagination and sorting.

ListViewsController

Lists PowerDNS views (5.0+) and the zones they contain. Also exposes inline add/remove actions. The whole feature is admin-only and hidden when the connected server cannot serve views, whether through its version, its backend or its views setting (capability gate).

SearchController

Handles the search page: finds zones and records by name or content with paging and sorting.

ZoneCatalogController

Manage which zones a producer zone publishes in its catalog.

ZoneOwnershipController

Handles the zone ownership page: adds and removes user and group owners of a zone.

BootstrapErrorResponder

Shapes an unhandled throwable into an HTTP response for the front controller.

ClientContext

The requesting client as resolved once per request: the address behind any trusted proxy and the sanitized user agent. Built by the composition root and handed to everything that logs, throttles or audits by client.

Request

Snapshot of the $_GET, $_POST and $_SERVER superglobals with typed accessors for controllers.

RequestContext

Static helpers classifying the current request from server globals: API route detection and JSON response negotiation.

ModuleManifest

The bundled modules, keyed by the name used under modules. in the configuration.

ChangeRequestPresenter

Shapes change requests for the list, review and edit-page templates.

EditZonePresenter

The zone editor's view model: maps the facts the controller has already resolved (zone, permissions, preferences, listing) onto the variables edit.html reads. Everything derived for the page - editability flags, record locks, the comment conflict, the offered record types - is computed here from those inputs alone.

OwnerGroupColumnPresenter

Prepares the zone-list owner and group cells: the first entries stay visible, the rest collapse into a "+N more" tooltip label.

OwnerOptionsPresenter

Which users a zone-owner picker offers, and which one it shows again after a refused submit. Whether the caller may pick other users is decided by the permission layer and passed in.

PaginationPresenter

Renders the Bootstrap page-number list for a Pagination object, with ellipses around the current page.

RecordLockPresenter

Decorates the zone editor's record rows with the display fields the template expects, and with whether each row may be edited.

ZoneStartingLettersPresenter

Renders the 0-9 and a-z letter filter links on the forward zone list page.

HeadlessRouteFilter

Removes the web interface from the route collection when interface.web_enabled is false, leaving an API-only (headless) surface.

SymfonyRouter

Matches the request against routes.yaml and enabled module routes, then runs the matched controller.

AuditService

Writes the "client_ip:.. user:.. operation:.." audit lines. Every line starts with the same actor context; one method per event keeps the field names in one place.

ApiKeyAuthenticationMiddleware

Authenticates API requests by the X-API-Key header and loads the key's user.

AuthenticationService

Starts or ends a session with a flash message, then redirects to login; API requests get a 401 JSON instead.

BasicAuthenticationMiddleware

Authenticates API requests with HTTP Basic credentials against the users table.

SessionAuthenticator

Per-request login pipeline: CSRF and reCAPTCHA on the form, session expiry, then the SQL or LDAP authenticator.

AvatarService

Resolves a user's avatar URL from an OAuth profile picture or Gravatar, per the interface.avatar_* settings.

ChangeApprovalContext

Answers what the change-approval feature means for one user: whether it is on, how their edits to a zone are handled, which zones they review, and how many requests are waiting.

ChangeRequestMessages

Words a ZoneChangeRequestService outcome for the web flash messages.

ChangeRequestNotificationService

Writes the zone audit line for each change request event, then emails the reviewers of the zone when a request is filed and the requester when it is decided. Mail failures are logged and reported as false; nothing here throws to the caller, so a mail problem never blocks a request.

ControllerEnvironment

Pre-built collaborators for a controller, bypassing the eager bootstrap (config file, database connection, session authentication) that BaseController::__construct() otherwise performs.

ControllerServiceFactory

The services controllers ask for, split by concern into five factories that each memoize their per-request instances. The flat accessors below delegate to them so call sites and test doubles keep one entry point.

CsrfTokenService

Generates, stores and validates the per-session CSRF token carried by the _token form field.

DashboardStatsService

The totals on the admin dashboard. Zone and record counts are null when they cannot be read, so the page still renders.

DatabaseService

Opens the PDO connection from the configured credentials, wrapping failures in a readable error.

DnsBackendProviderFactory

Factory for creating DNS backend provider instances.

DnsDataService

Orchestration service for DNS data reads.

DnsServiceFactory

Builds the DNS manager services with their backend provider and repositories.

DnssecProviderFactory

Builds the DNSSEC provider for the configured PowerDNS API, or a null provider when the API is not set up.

DynamicDnsRequestFactory

Builds the dyndns2 request value object and the update service that handles it.

EmailTemplateService

Renders the transactional email templates under templates/emails, with custom overrides, through Twig.

AuthServices

Sessions, credentials, MFA, API keys and the audit trail. The session, redirect and authentication services are one instance per request.

BackendServices

The connection to the DNS backend: the provider, its API client, and the repositories and record managers that read and write through it. Every memoized instance is shared for the request so read caches are not split.

RecordServices

Record writes and the change-approval flow around them: managers, reverse record creation, comments, and the change request pipeline.

UserServices

Users, groups, permissions and preferences. The permission service is memoized so its per-user cache spans the whole request.

ZoneServices

Zone lifecycle: creation, ownership, templates, signing, metadata and the zone lists.

GroupMembershipService

Adds and removes users from groups and lists a group's members.

GroupService

Creates, updates, deletes and lists user groups, with the view checks the group pages need.

LdapAuthenticator

Session login against an LDAP directory, with lockout tracking, a cached bind result and MFA hand-off.

LocaleResolver

Resolves the interface language for the current request.

LoginAttemptService

Records attempts in login_attempts and enforces the password- and MFA-stage lockouts per user and IP.

MailService

Sends application email over the configured transport: PHP mail(), sendmail, SMTP or the log.

MfaVerificationMailer

Renders the MFA verification email through Twig and sends it with MailService.

OidcConfigurationService

Reads the oidc provider settings, discovers endpoints and validates the permission template mapping.

OidcService

Runs the OIDC login flow: builds the authorization redirect and turns the callback into a session.

PaginationService

Builds Pagination objects and resolves the rows-per-page value within the allowed bounds.

PasswordChangeService

Changes the logged-in user's own password after verifying the current one; LDAP users are refused.

PasswordGenerationService

Generates random passwords that satisfy the configured password policy.

PasswordPolicyService

Checks a password against the security.password_policy rules and reports the ones it fails.

PasswordResetService

Password reset by email: issues and rate-limits tokens, validates them and stores the new password.

PdnsVersionService

Detects and caches the connected PowerDNS server version so admins can see it in the UI and so error reports include it without a manual lookup.

PermissionTemplateWriteService

The single guarded entry point for permission template writes.

PowerdnsStatusService

Reads server info and metrics from the PowerDNS API and probes secondary servers for the status page.

RecaptchaService

Verifies reCAPTCHA v2/v3 responses with Google for the login form.

RecordAddAccess

Whether a user may add records to a zone directly, as RecordAddService::open() answers it. Each add-record entry point words the refusal codes itself.

RecordAddMessages

Words a successful RecordAddResult for the add-record page and the zone editor.

RecordAddResult

Outcome of adding one record from a form, with the companion PTR or A record the operator asked for alongside it.

RecordCommentService

Reads and writes the comment attached to a record.

RecordCommentSyncService

RejectedZoneEditPresenter

RepositoryFactory

RequestValidator

SamlConfigurationService

SamlService

SearchCriteria

SqlAuthenticator

StatsDisplayService

UrlService

ZoneMetadataFormMessages
