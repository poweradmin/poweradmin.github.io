Classes

AppManager

Builds the Twig environment with theme, translator and extensions, and renders templates for web controllers.

BootContext

What Kernel::boot() built for this process: the configuration, the logger, the loaded module registry and, once something asks for it, the database.

Kernel

The one place a process is booted: index.php, dynamic_update.php, install/index.php and bin/poweradmin all call boot() and work from the BootContext it returns. Nothing below the entry points reaches for the configuration singleton.
