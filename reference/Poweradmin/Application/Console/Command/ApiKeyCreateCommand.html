ApiKeyCreateCommand

final class ApiKeyCreateCommand implements CommandInterface (View source)

api-keys:create - issues an API key owned by the acting user (--user=) and prints the secret once. ApiKeyService enforces the same rules as the web form: API enabled, api_manage_keys or ueberuser, and api.max_keys_per_user.
