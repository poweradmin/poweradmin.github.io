ModuleServices

interface ModuleServices (View source)

The module-facing service surface: the collaborators a module controller may obtain from the core through BaseController::moduleServices().

Modules under lib/Module depend on the core only through this interface, the ModuleInterface contract and the SDK value types RecordAddResult, RecordAddAccess, ChangeRequestMessages, ZoneCreateRequest and ZoneCreateFormMessages. A method is added here when a module needs it; the rest of ControllerServiceFactory is core-only.
