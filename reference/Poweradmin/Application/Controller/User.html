Poweradmin\Application\Controller\User

Classes

AddGroupController

Handles the add-group form at /groups/add: validates the name and group template, then creates the group.

AddPermTemplController

Handles the add-permission-template form: validates the fields and creates the template with its permissions.

AddUserController

Handles the add-user form: guards the template choice, creates the user, assigns groups and mails credentials.

ApiKeysController

Renders the API key list page and links to the add, edit, delete and regenerate actions.

DeleteGroupController

Handles the delete-group confirmation page and deletes the group on confirmed POST.

DeletePermTemplController

Handles the delete-permission-template confirmation page and deletes the template on confirmed POST.

DeleteUserController

Handles the delete-user page: deletes the user and transfers or deletes each of their zones as chosen.

EditGroupController

Handles the edit-group form: updates the name, description and permission template of a group.

EditPermTemplController

Handles the edit-permission-template form: updates the template's details and permission set.

EditUserController

Handles the edit-user form: updates the profile, password, template and group memberships of a user.

ListGroupsController

Renders the groups list page at /groups.

ListPermTemplController

Renders the permission templates list at /permissions/templates.

ManageGroupMembersController

Handles the group members page: adds and removes users in a group.

ManageGroupZonesController

Handles the group zones page: assigns zones to a group and removes them.

QuickRemoveGroupMemberController

Handles the POST that removes one user from a group from the edit-group page.

QuickRemoveGroupZoneController

Handles the POST that removes one zone from a group from the edit-group page.

RemoveUserGroupController

Handles the POST that removes a user from one group from the edit-user page.

UserPreferencesController

Handles the user preferences page: rows per page, form positions, display toggles and timezone.

UsersController

Renders the users list and saves the inline edits submitted from it.
