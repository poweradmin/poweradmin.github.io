Classes

AbstractApiController

Shared base for API controllers: enforces the api.enabled switch, parses JSON input and shapes JSON responses.

DocsController

Serves the Swagger UI page at /api/docs when API documentation is enabled.

HeadlessNotFoundController

Answers every miss on a headless install, where there is no web interface to render a 404 page with.

HealthController

Unauthenticated readiness probe reporting whether Poweradmin can reach its own dependencies. Disabled by default.

InternalApiController

Base for session-authenticated internal API endpoints: requires a login and the X-CSRF-Token header on writes.

PublicApiController

Base for /api/v2 endpoints: API key or Basic auth, key scope enforcement, request logging and wrapped responses.

V1GoneController

Answers every /api/v1 path with 410 Gone and a pointer to v2.
