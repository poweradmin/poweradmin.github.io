Poweradmin\Application\Controller\System

Classes

AddSupermasterController

Handles the add-supermaster form: validates the IP and nameserver, then stores the supermaster entry.

DatabaseConsistencyController

Renders the database consistency page for admins and applies the fix actions it offers.

DeleteSupermasterController

Handles the delete-supermaster confirmation page and removes the supermaster on confirmed POST.

EditSupermasterController

Handles the edit-supermaster form: updates the IP, nameserver and account of a supermaster.

IndexController

Renders the dashboard after login with the cards allowed by the user's permissions.

ListSupermastersController

Renders the supermasters list at /supermasters.

NotFoundController

Answers unmatched routes with a 404 page, or a JSON error for API callers.

PdnsStatusController

Renders the PowerDNS server status page from the API's server info and statistics.

PingController

Unauthenticated liveness probe. Answers if the process can serve a request and checks nothing else, so it still reports ok while the database is down.

StaticAssetController

Serves static assets like CSS, JS, images and fonts.
