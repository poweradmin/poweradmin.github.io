Poweradmin\Application\Controller\Auth

Classes

ChangePasswordController

Handles the change-password form for the logged-in user; LDAP, OIDC and SAML users are refused.

ForgotPasswordController

Handles the forgot-password form: takes an email address and sends the password reset link.

ForgotUsernameController

Handles the forgot-username form: sends the username to the submitted email address if it is on file.

LoginController

Renders the login page with its CSRF token and the enabled OIDC and SAML providers.

LogoutController

Logs the user out, clearing the session and redirecting to the OIDC or SAML provider's logout when used.

MfaSetupController

Handles the MFA setup page: app or email enrolment, verification, disabling and recovery code regeneration.

MfaVerifyController

Handles the MFA verification step after login, with throttling of failed attempts.

OidcCallbackController

Handles the OIDC provider callback at /oidc/callback: completes the login or reports the provider error.

OidcLoginController

Starts the OIDC login flow by redirecting to the chosen or first configured provider.

ResetPasswordController

Handles the password reset form reached from the emailed token link and sets the new password.

SamlCallbackController

Handles the SAML assertion (/saml/acs) and single logout (/saml/sls) endpoints.

SamlLoginController

Starts the SAML login flow by redirecting to the chosen or first configured identity provider.

SamlMetadataController

Serves the SAML service provider metadata XML at /saml/metadata.

UserAgreementController

Handles the user agreement page: shows the text and records the user's acceptance.
