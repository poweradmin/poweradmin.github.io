Kernel

final class Kernel (View source)

The one place a process is booted: index.php, dynamic_update.php, install/index.php and bin/poweradmin all call boot() and work from the BootContext it returns. Nothing below the entry points reaches for the configuration singleton.

static BootContext
boot(BootOptions|bool $web)

Loads the configuration once, applies the timezone and session policy, builds the logger and the module registry, and opens the database when the entry point wants it up front.

static ControllerEnvironment
controllerEnvironment(BootContext $context, bool $authenticate)

What a web controller needs beyond the booted context: the PHP extensions and the configuration file present, the gettext locale set, the database open and, unless the controller serves anonymous requests, the session authenticated. Runs once per controller; the checks are idempotent.
