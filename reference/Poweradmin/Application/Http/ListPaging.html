ListPaging

final class ListPaging (View source)

Opt-in paging and substring filtering for API list endpoints. paginate() and filterContains() serve lists that are already loaded, e.g. records, which come from the PowerDNS API in API backend mode; isPastEnd() and extra() also serve lists paged in SQL, such as change requests.

Paging follows GET /change-requests: nothing is paged without per_page (or with 0); with it, page starts at 1 and per_page is capped.
