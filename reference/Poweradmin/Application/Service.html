Poweradmin\Application\Service

Classes

ApiStatusService

Tracks the most recent PowerDNS API error so the UI can surface it.

AuditService

Writes the "client_ip:.. user:.. operation:.." audit lines. Every line starts with the same actor context; one method per event keeps the field names in one place.

AvatarService

Resolves a user's avatar URL from an OAuth profile picture or Gravatar, per the interface.avatar_* settings.

ControllerEnvironment

Pre-built collaborators for a controller, bypassing the eager bootstrap (config file, database connection, session authentication) that BaseController::__construct() otherwise performs.

ControllerServiceFactory

Builds the repositories and domain services controllers ask for, and memoizes the per-request shared instances (backend provider, permission cache). Owns the wiring so BaseController only exposes thin accessors.

CsrfTokenService

Generates, stores and validates the per-session CSRF token carried by the _token form field.

DashboardStatsService

The totals on the admin dashboard. Zone and record counts are null when they cannot be read, so the page still renders.

DatabaseService

Opens the PDO connection from the configured credentials, wrapping failures in a readable error.

DnsBackendProviderFactory

Factory for creating DNS backend provider instances.

DnsDataService

Orchestration service for DNS data reads.

DnssecProviderFactory

Builds the DNSSEC provider for the configured PowerDNS API, or a null provider when the API is not set up.

DynamicDnsRequestFactory

Builds the dyndns2 request value object and the update service that handles it.

EmailTemplateService

Renders the transactional email templates under templates/emails, with custom overrides, through Twig.

GroupMembershipService

Adds and removes users from groups and lists a group's members.

GroupService

Creates, updates, deletes and lists user groups, with the view checks the group pages need.

LdapAuthenticator

Session login against an LDAP directory, with lockout tracking, a cached bind result and MFA hand-off.

LocaleResolver

Resolves the interface language for the current request.

LoginAttemptService

Records attempts in login_attempts and enforces the password- and MFA-stage lockouts per user and IP.

MailService

Sends application email over the configured transport: PHP mail(), sendmail, SMTP or the log.

MfaVerificationMailer

Renders the MFA verification email through Twig and sends it with MailService.

OidcConfigurationService

Reads the oidc provider settings, discovers endpoints and validates the permission template mapping.

OidcService

Runs the OIDC login flow: builds the authorization redirect and turns the callback into a session.

PaginationService

Builds Pagination objects and resolves the rows-per-page value within the allowed bounds.

PasswordChangeService

Changes the logged-in user's own password after verifying the current one; LDAP users are refused.

PasswordGenerationService

Generates random passwords that satisfy the configured password policy.

PasswordPolicyService

Checks a password against the security.password_policy rules and reports the ones it fails.

PasswordResetService

Password reset by email: issues and rate-limits tokens, validates them and stores the new password.

PdnsVersionService

Detects and caches the connected PowerDNS server version so admins can see it in the UI and so error reports include it without a manual lookup.

PermissionTemplateWriteService

The single guarded entry point for permission template writes.

PowerdnsStatusService

Reads server info and metrics from the PowerDNS API and probes secondary servers for the status page.

RecaptchaService

Verifies reCAPTCHA v2/v3 responses with Google for the login form.

RecordAddMessages

Words a successful RecordAddResult for the add-record page and the zone editor.

RecordAddResult

Outcome of adding one record from a form, with the companion PTR or A record the operator asked for alongside it.

RecordAddService

The add-record flow shared by the add-record page and the inline form on the zone editor: name and content are normalised the same way, the TTL default is resolved the same way, and the companion PTR or A record follows the same rules.

RecordCommentService

Reads and writes the comment attached to a record.

RecordCommentSyncService

Keeps the comment on an A/AAAA record and its PTR counterpart in sync when either is created or edited.

RecordManagerService

Creates a record through RecordManager, then logs it, stores its comment and syncs the PTR comment.

RejectedZoneEditPresenter

Puts a zone-editor submission that was refused as stale back into the freshly read record listing, so the warning does not also cost the operator their edits.

RepositoryFactory

Centralized factory for creating repository instances.

RequestValidator

Validates controller request data against Symfony constraints.

ResultPaginator

In-memory sorting, filtering, and pagination for datasets.

SamlConfigurationService

Reads the saml provider and SP settings and builds the OneLogin toolkit settings array.

SamlService

Runs the SAML login flow: builds the IdP redirect, consumes the assertion and handles single logout.

SearchCriteria

Value object holding the search parameters the search page works with.

SqlAuthenticator

Session login against the users table with lockout checks, hash upgrades and MFA hand-off.

StatsDisplayService

Renders the memory usage and elapsed time footer shown when misc.display_stats is on.

UrlService

Builds absolute URLs for emails and redirects from the configured base URL.

UserAuthenticationService

Hashes and verifies user passwords across bcrypt, argon2 and the legacy md5 formats.

UserFormMessages

Words a refused UserManagementService write for the user forms. The service's own message is the API wording; password policy, field length and external-auth password messages are the same on both sides and pass through.

UserProvisioningService

Creates or updates the local user for an LDAP, OIDC or SAML login and maps their groups to a permission template.

UsernameRecoveryService

Username recovery by email: rate-limits requests and mails the usernames registered to an address.

ZoneAccessNotificationService

Emails a user when they gain or lose access to a zone.

ZoneCreateFormMessages

Words a refused ZoneManagementService::createZone() for the add-zone forms.

ZoneGroupService

Assigns zones to groups and removes them; the group-based half of zone ownership.

ZoneMetadataFormMessages

Words a refused ZoneMetadataService write for the metadata editor.

ZoneOwnershipFormResolver

Reads the owner and group fields of the add-zone forms and applies the shared ownership rules. The forms drop what the ownership mode disallows instead of rejecting it, and word the refusals in the user's language.

ZoneSaveMessages

Words a ZoneEditService save for the zone editor's flash message.

ZoneSigningMessages

Words a ZoneSigningService outcome for the web pages that sign or unsign an existing zone.

ZoneSyncService

Synchronizes zone metadata between the PowerDNS API and the local zones table.
