ZoneDetail

final class ZoneDetail implements ArrayAccess (View source)

One zone with its ownership, as read by ZoneReadRepositoryInterface::getZone().

Both the SQL and the API backend build it through fromRow(), so the key set the internal API and the templates see is defined once. Reading it as an array (zone['name'] in Twig, toArray() for JSON) yields the legacy column-keyed shape.
