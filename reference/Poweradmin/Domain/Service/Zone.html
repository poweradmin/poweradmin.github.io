Poweradmin\Domain\Service\Zone

Classes

CatalogZoneService

Catalog zone membership.

ChangeApprovalPolicy

Pure rules for the opt-in change approval workflow: whether a user's zone changes are written directly, filed as a change request, or refused, and who may review a request.

ForwardZoneAssociationService

Maps each reverse zone to the forward zones its PTR records point at, with a PTR count per forward zone.

ZoneAccountSyncService

Mirrors zone ownership into the PowerDNS account field.

ZoneChangeRequestResult

Outcome of filing, approving, rejecting or cancelling a change request.

ZoneChangeRequestService

Files zone change requests and applies the reviewer's decision.

ZoneCountService

Counts the zones a user may see; the backend-specific query lives in the zone repository.

ZoneCreateOwnershipResolver

Resolves the user-owner and group-owner assignment for a new zone, applying the active zone_ownership_mode and permission rules. The API hands in its JSON body; the web forms hand in the owner and groups they already parsed.

ZoneEditRowChange

One posted editor row that differs from the zone: the normalised row as it will be written and the log holding the stored state it replaces.

ZoneEditService

Saves the zone editor's record table: the edit gate, the stale-form check, the per-row diff and write, the record and zone comments, and the SOA serial bump that closes a save.

ZoneEditSubmission

One submission of the zone editor's record table, as posted.

ZoneManagementService

Creates zones for the API with the same checks the web form applies. Failures come back as

message is the API wording, the code lets the web forms word it themselves.

ZoneMetadataResult

Outcome of a ZoneMetadataService write, with the metadata kind and options the caller needs to word a refusal.

ZoneMetadataService

The zone metadata rules the editor and the API share: what a kind accepts, who may change it, what the active backend can store, and how a change is persisted and logged. Callers parse their input and word the refusals.

ZoneOverlapService

Blocks creating a zone that overlaps an existing zone owned by another user.

ZoneOwnershipIndex

Who owns which of a page of zones, resolved once so per-row controls do not query per zone. Ownership is direct (zones.owner) or through any group the user belongs to.

ZoneOwnershipModeService

Resolves the dns.zone_ownership_mode setting into ownership-side flags.

ZoneOwnershipResolution

Outcome of {ZoneCreateOwnershipResolver}: either a resolved owner/group assignment for the new zone, or an error with HTTP status. The error carries a code so the web forms can word it themselves; the message is the API text.

ZoneSaveResult

How a zone editor save ended, with what the page needs to report it and, for a refused stale form, the rows to put back in front of the operator.

ZoneSigningResult

Outcome of a ZoneSigningService sign or unsign request plus the detail text callers may show.

ZoneSigningService

Signs and unsigns zones the one way every entry point agrees on: refuse presigned zones and invalid zones, bump the SOA serial so secondaries notice, verify what PowerDNS reports afterwards, rectify, and audit.

ZoneSortingService

Resolves the zone list's sort column, direction and reverse-zone filter from submitted values and the session.

ZoneValidationService

Checks a zone is fit for DNSSEC signing and formats the reasons when it is not.
