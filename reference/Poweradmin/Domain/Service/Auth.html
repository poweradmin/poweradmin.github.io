Poweradmin\Domain\Service\Auth

Classes

ApiKeyService

Creates, regenerates, disables and deletes API keys and enforces the per-user key limit.

ApiKeyWriteResult

Outcome of an API key write: the saved key on success, otherwise the reason, its code and the refusal.

ApiPermissionService

Permission gate for the public API. A facade over PermissionService so the API and the web UI share one oracle; group and visible-zone lookups read the user repository.

DynamicDnsAuthenticationService

Checks a DDNS client's password (with login-attempt lockout) and which zones that user may update.

MfaService

TOTP, email-code and recovery-code verification, MFA enrolment, QR code rendering and enforcement checks.

PasswordEncryptionService

AES-256-CBC encryption for the password held in the session, keyed from the configured session_key.

PermissionService

Answers permission questions for a user from their template and group grants, cached per request.

PermissionTemplateAssignmentGuard

Gates perm_templ assignment on user create/update API paths.

PermissionTemplateContentGuard

Gates what a permission template may contain.

SelfEditFieldGuard

Gates auth-critical fields on user self-edit API paths (#1327).

SessionKeys

Catalogue of the login and user identity $_SESSION keys.

SessionPromotionService

Promotes the half-authenticated pending session into a fully authenticated one.

UserContextService

Session-backed identity of the current user (id, username, auth method) and the session storage controllers use. Domain rules read the actor through ActorInterface instead.

ZoneAccessPolicy

Pure rules for what a user may change on the zone edit screens.

ZoneListPermissionService

Builds the ownership index the zone lists and the search page use to decide per-row edit/delete controls and owner-column visibility.
