PostWriteZoneRectifier

final class PostWriteZoneRectifier (View source)

Rectifies a zone after records were written, so the NSEC/NSEC3 ordering data of a signed zone follows nodes being added or removed.

Constants

private SLOW_FAILURE_SECONDS

A failure this slow means PowerDNS timed out or stalled, not that it refused one zone.

void
rectify(string $zoneName)

The write is already committed, so a failure here is logged, not raised. After one slow failure the rest of the request skips rectify, so a bulk write cannot stall per zone; a slow success never trips it.
