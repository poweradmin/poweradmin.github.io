Poweradmin\Domain\Service\User

Classes

CreateUserCommand

What a create-user request asks for, typed and independent of the wire format. The controllers build it from their own field names; the service hands it on to the repository with the password in its stored form.

GroupReferenceResolver

Turns a submitted list of group references into distinct group entities

UpdateUserCommand

What a partial user update asks for: every field is null when the request left it alone. The controllers build it from their own field names; the service hands it on to the repository with the password in its stored form.
