TemplateRecordLinkRepositoryInterface

interface TemplateRecordLinkRepositoryInterface (View source)

Tracks which zone records a template application wrote, so a later application of the same template can remove exactly those records.

SQL backends key the link on the numeric records.id; the API backend keys it on the encoded record identifier and keeps it in a separate table.
