static string getReverseRecordNameSortOrder(string $table, string $dbType, string $direction = 'ASC', string $zoneName = 'in-addr.arpa')

ORDER BY clause that sorts the record names of an in-addr.arpa zone in IP order.

The zone's own labels are the same on every record, so they are cut off and the labels below it are compared as numbers, right to left: 10.0.2.5 comes before 10.0.10.5. The apex (nothing left) comes first, labels that are not numbers come last, and the natural name sort breaks ties. Evaluated per row, so it is a filesort, as the natural sort already is.

static string orderBy(array $sort, array $columns, string $tiebreaker, string $default)

ORDER BY for an API list sorted in SQL, from the keys ListSort::fields() returns.

Each allowed field maps to a fixed column, or to a closure that gets ASC or DESC and returns the clause (e.g. a natural name order), so request input never reaches the SQL. The tiebreaker comes last so pages stay stable when sort values repeat; without sort keys the list keeps its default order.
