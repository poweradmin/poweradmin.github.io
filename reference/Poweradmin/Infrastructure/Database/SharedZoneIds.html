SharedZoneIds

final class SharedZoneIds (View source)

Ownership under a zone id collision in API backend mode.

A zone this application created and a zone migrated from SQL mode can share a canonical id. The id then resolves to one of them (see CanonicalZoneSql::selectByZoneId()), but the extra-owner rows and group grants keyed by that id belong to both, so they would let the other zone's owners act on it. For a shared id only the direct owner of the row it resolves to counts.
