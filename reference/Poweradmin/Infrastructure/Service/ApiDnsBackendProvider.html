ApiDnsBackendProvider

final class ApiDnsBackendProvider implements DnsBackendProviderInterface (View source)

PowerDNS REST API-based DNS backend provider.

Performs all DNS operations through the PowerDNS REST API. Zone metadata is stored locally in the Poweradmin zones table. Records are identified by encoded composite keys (no PowerDNS DB access needed).
