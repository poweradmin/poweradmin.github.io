Poweradmin\Infrastructure\Logger

Classes

AuditLogWriter

Sink for audit lines: hands each one to the syslog logger and, when database logging is on, to the log_users, log_zones, log_groups or log_api table.

ClassContextLogger

PSR-3 decorator that tags every log call with the owning class's short name in the classname context key.

DbApiLogger

Writes API events to the log_api table and queries, filters and prunes them for the API log page.

DbGroupLogger

Writes group events to the log_groups table and queries them, joined to user_groups, for the group log page.

DbUserLogger

Writes user events to the log_users table and queries them with filters for the user log page.

DbZoneLogger

Writes zone events to the log_zones table and queries them by domain or filter, with SQL and API-backend joins.

Logger

PSR-3 logger that applies the logging.level threshold, fills {placeholders} and passes lines to a log handler.

NativeLogHandler

Log handler that formats a line with DEFAULT_LOG_FORMAT and sends it to PHP's error_log (the SAPI log).

RecordChangeLogger

Writes before/after record and zone snapshots to log_record_changes, grouped into log_changesets rows.

SyslogLogger

PSR-3 logger that writes every message to syslog under the configured identity and facility.

Interfaces

LogHandlerInterface

Output sink for the PSR-3 Logger.
