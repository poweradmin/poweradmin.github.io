AuditLineValue

final class AuditLineValue (View source)

Makes values safe for the "name:value" audit lines, which fail2ban filters read for client_ip and operation. A value must not break the line or pass for another field.

Methods

static string
of(string $value)

No control characters, and no "word:" that could pass for a field. Colons after digits (IPv6 addresses, times) stay readable.

static string
user(string $username)

A username as the user: field stores it. Every colon is encoded, so the log filters can build the same form from a username, in PHP or with SQL REPLACE().
