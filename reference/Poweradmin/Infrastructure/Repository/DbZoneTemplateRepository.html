DbZoneTemplateRepository

class DbZoneTemplateRepository implements ZoneTemplateRepositoryInterface (View source)

SQL persistence for zone templates in zone_templ and their records in zone_templ_records.

The zone listings join the PowerDNS tables on SQL backends; on the API backend they read the Poweradmin-native zones table only and take zone details from the backend provider.
