Interfaces

CommandInterface

One bin/poweradmin command. The metadata is static so the registry can print usage and validate options before the service graph is booted.

ModuleServices

The module-facing service surface: the collaborators a module controller may obtain from the core through BaseController::moduleServices().

PageOutputInterface

Where a controller's pages go: the themed chrome and body in production (PageRenderer), a recorder in tests. A controller hands over the template and the parameters exactly as it built them.

ConfigurationInterface

Read access to settings by group and key.

ModuleInterface

A feature module: its routes, navigation items, capabilities and templates, enabled through configuration.

ActorInterface

Who is acting in the current request: the session user on the web, the key owner on the API. Domain rules ask this instead of reading the session.

ApiStatusInterface

Exposes the most recent PowerDNS API error so domain checks can tell an outage from an empty backend.

ApiStatusRecorderInterface

Records or clears the most recent PowerDNS API error; the API client and backend provider write through this.

AuditLoggerInterface

The audit events domain services record; the Application layer owns the line format and the actor context.

BackendCapabilitiesInterface

Capability probe telling callers which kind of DNS backend they hold.

CatalogBackendInterface

Catalog zone membership reads and writes against the DNS backend.

ChangeRequestNotifierInterface

Told about change request events so people can be notified. Implementations must not throw; a failed notification never undoes the event.

DnsBackendProviderInterface

PowerDNS data access (domains, records, supermasters) over direct SQL or the PowerDNS API; Poweradmin-native tables stay on SQL.

DnssecProviderInterface

DNSSEC operations for one zone.

EmailTemplateRendererInterface

Renders the account emails a preview tool can show; the Application layer owns the templates and their custom overrides.

LoginThrottleInterface

Records login attempts and reports lockouts; the Application layer owns the storage and thresholds.

MfaVerificationMailerInterface

Delivers MFA email verification codes; the Application layer owns the template and transport.

PasswordHasherInterface

Hashes and verifies user passwords; the Application layer owns the algorithm and cost settings.

PasswordPolicyInterface

Checks a password against the configured policy rules; the Application layer owns the configuration.

ProxyContextInterface

Merges the outbound HTTP proxy, when one applies to the URL, into a set of PHP stream context options.

PublicSuffixInterface

Splits a hostname on the public suffix boundary, so that names under a multi-label suffix such as co.uk or com.pl are divided where registration actually happens rather than on the last dot.

QrCodeRendererInterface

Renders a string as a QR code for display in a page.

RecordChangeWriterInterface

Records before/after snapshots of record and zone changes for the change log.

RecordCommentEditorInterface

The per-record comment reads and writes the zone editor needs; the Application layer owns the storage.

RecordCommentSyncInterface

Carries an edited record's comment over to its A/AAAA or PTR counterpart.

RecordReadBackendInterface

Record lookups by id, name or zone read from the DNS backend.

RecordSearchInterface

The search page's record half: matching records with their zone owner, paged and sorted, and the unpaged match count. Rows carry disabled as a bool.

RecordWriteBackendInterface

Record add, edit and delete writes against the DNS backend.

ReverseZoneSorterInterface

Orders reverse zone names in PHP by the configured sort type.

SearchBackendInterface

Wildcard search over zones and records in the DNS backend.

SerialBackendInterface

SOA serial handling: whether PowerDNS bumps the serial itself and the zone serial policy metadata.

SessionInterface

The request's session store. One implementation wraps PHP's own session, the other keeps the values in memory for tests and for request-scoped caches.

SupermasterBackendInterface

Supermaster (autoprimary) reads and writes against the DNS backend.

TotpInterface

Time-based one-time passwords, as used by authenticator apps.

TransactionInterface

The request's unit of work: one transaction shared with every repository that writes through the same connection.

ZoneKeyManagementInterface

DNSSEC key lifecycle for a zone, plus the DS and DNSKEY records derived from its keys.

ZoneReadBackendInterface

Zone lookups, listings, record counts and SOA health read from the DNS backend.

ZoneRectifierInterface

Rectifies a zone after its records change so the DNSSEC ordering data stays valid.

ZoneSearchInterface

The search page's zone half: matching zones with their owners, paged and sorted, and the unpaged match count. Each backend keeps its own row shape.

ZoneSigningInterface

Signing state of a zone: securing, unsecuring and reading whether it is signed.

ZoneWriteBackendInterface

Zone create, delete, kind, primary, account and AXFR-retrieve writes against the DNS backend.

ApiKeyRepositoryInterface

Persistence for API keys.

AuthUserLookupInterface

The account rows the authenticators read while deciding a login.

DomainRepositoryInterface

Lookups on the domains table; implemented for SQL and for the API backend mode.

DynamicDnsRepositoryInterface

Persistence for the dynamic DNS update endpoint.

ExternalIdentityRepositoryInterface

Persistence for the OIDC and SAML identity links that tie a provider subject to a local user.

LoginAttemptRepositoryInterface

Persistence for the login_attempts counters the authentication throttle reads and writes.

PasswordResetTokenRepositoryInterface

Persistence for password reset tokens and their rate-limit counters.

PermissionTemplateRepositoryInterface

Persistence for permission templates and the permission items they bundle.

RecordCommentRepositoryInterface

Persistence for RRset-level record comments; both backends implement it.

RecordLinkedCommentRepositoryInterface

Comments linked to individual records through record_comment_links.

RecordListingInterface

Zone-wide record listing, filtering, counting and RRset reads.

RecordLookupInterface

Single-record reads and existence checks within a zone.

RecordRepositoryInterface

Reads on the records table; implemented for SQL and for the API backend mode.

RecordTypeDefaultRepositoryInterface

Persistence for admin-configured default TTLs per record type.

RepositoryFactoryInterface

Builds the repositories a domain service needs on demand; the Application layer picks the SQL or API implementation for the configured backend.

TemplateRecordLinkRepositoryInterface

Tracks which zone records a template application wrote, so a later application of the same template can remove exactly those records.

UserAdminInterface

Account administration: listing, creating, updating and deleting users and moving their zones.

UserAgreementRepositoryInterface

Persistence for the user agreement versions each user has accepted.

UserCredentialWriterInterface

Write access to a user's stored password.

UserGroupLookupInterface

Read access to user groups and their membership by user.

UserGroupMemberRepositoryInterface

Persistence for user group membership.

UserGroupRepositoryInterface

Persistence for user groups.

UserGroupWriterInterface

Creating, updating and deleting groups, plus the counts that guard a delete.

UserLookupInterface

Read access to individual user accounts by id, name or email.

UserMfaRepositoryInterface

Persistence for per-user MFA settings.

UserNotificationRecipientInterface

The account rows the notification mailers address their messages to.

UserPermissionReadInterface

Read access to what a user may do: permissions, uberuser status, template grants and zone ownership.

UserPreferenceRepositoryInterface

Persistence for per-user interface preferences.

UserRepositoryInterface

Persistence for user accounts and the zones they own.

UsernameRecoveryRepositoryInterface

Persistence for username recovery attempts and their rate-limit counters.

ZoneAccountOwnerLookupInterface

Resolves the owner whose username the PowerDNS account field mirrors.

ZoneChangeRequestRepositoryInterface

Persistence for zone change requests. Lists come back newest first.

ZoneGroupRepositoryInterface

Persistence for group-based zone ownership.

ZoneMetadataStoreInterface

Where a zone's metadata rows live: the domainmetadata table on the SQL backend, or the PowerDNS API (metadata plus zone-object properties) on the API backend. Rows are [['kind' => string, 'content' => string], ...].

ZoneOwnershipRepositoryInterface

Zone ownership reads and writes; one of the three roles ZoneRepositoryInterface combines.

ZoneReadRepositoryInterface

Zone lookups, lists and counts; one of the three roles ZoneRepositoryInterface combines.

ZoneRepositoryInterface

Zone reads and ownership writes; implemented for SQL and for the API backend mode.

ZoneSerialReadInterface

Read access to zone SOA serials.

ZoneTemplateRepositoryInterface

Persistence for zone templates (zone_templ), their records (zone_templ_records) and the zone -> template links kept in zones.zone_templ_id.

ZoneTemplateSyncRepositoryInterface

Tracks which zones are out of date against their template after the template changes.

ZoneWriteRepositoryInterface

Zone row, comment and metadata writes (plus the metadata read the editor pairs with them); one of the three roles ZoneRepositoryInterface combines.

ConsistencyCheckerInterface

Finds and repairs ownerless zones, masterless slave zones, orphaned records and missing or duplicate SOAs. One implementation per DNS backend.

DnsRecordValidatorInterface

Validator for one record type; DnsValidatorRegistry picks the implementation.

DnsRecordValidationServiceInterface

Validates a record before it is written.

DomainManagerInterface

Zone creation, update and deletion.

RecordManagerInterface

Record creation, update and deletion.

SOARecordManagerInterface

SOA record and serial handling.

UserInfoInterface

User details returned by an external login provider (LDAP, OIDC or SAML).

LogHandlerInterface

Output sink for the PSR-3 Logger.
